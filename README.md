# 💰 Expense Tracker App (Full-Stack)

> **Status:** 🚧 In Progress / Active Development

A secure full-stack web application designed to help users manage and track their personal expenses efficiently, built with a robust Spring Boot backend and a modern frontend interface.

---

## 🚀 Tech Stack

* **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA / Hibernate, MySQL
* **Frontend:** HTML, CSS, JavaScript
* **Tools & Version Control:** Git, GitHub, Postman, Maven

---

## ✨ Current Features (Implemented)

* **User Authentication:** Secure user registration and login system with token/session management.
* **User-Specific Tracking:** Each user can only view, add, and manage their own expense records securely.
* **Data Transfer Objects (DTO):** Implemented the DTO pattern for clean data transfer between layers.
* **Request Validation:** Input validation checks on API endpoints to ensure data integrity.
* **Layered Architecture:** Controller, Service, Repository, and Domain structure following industry standards.

---
